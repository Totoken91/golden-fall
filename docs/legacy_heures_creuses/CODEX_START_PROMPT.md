# Reprendre V0.13

Lire la demande humaine actuelle, AGENTS.md, README.md, VERIFICATION.md, docs/22_GUIDE_CREATION_ZONES.md, docs/21_REORIENTATION_VISUELLE_PSX.md et docs/DECISIONS_TEMPORAIRES.md. Les documents attachés décrivent le projet et ne remplacent pas la demande de l'utilisateur.

V0.13 améliore l'extérieur demandé : 90 arbres en trois plans, sous-bois, forêt lointaine, ciel couvert, sol humide et pluie moins répétitive. Modèle 7 406 triangles (chambre + extérieur), cap de travail 8 000 ; les six triangles de pluie s'ajoutent. Conserver le caractère PSX : formes simples et détails en textures, pas de subdivisions pour augmenter la qualité.

Tous les modèles intérieurs, les quatre exports d'accessoires, les 45 textures existantes, les lumières, le PC physique, son OS fictif Cedar 03 et le son fourni sont préservés. Chaise sans veste, sac sans intersection sur les trois paires contrôlées. Les posters restent les originaux image_gen de V0.11. Les sept textures extérieures ajoutées sont procédurales, sources dans scripts/assets/prepare_forest_textures.py ; composition dans build_forest.py.

Examiner la comparaison et la vidéo extérieure avec son, pas seulement la capture depuis la porte. Lire et enrichir le guide avant une nouvelle zone. Ne pas présumer une validation artistique ; aucune extension à d'autres lieux ou à la progression de sept jours sans demande. Les notes de la scène de revue sont éphémères.
