# Posters — imagegen intégré

Deux illustrations originales générées le 9 octobre 2026 à la demande explicite de l'utilisateur. Outil : **image_gen intégré**, aucun appel CLI de secours. Les titres existaient déjà dans la chambre.

- [Morrow Creek — original](morrow_creek.png)
- [The Long Way Home — original](the_long_way_home.png)
- [Prompts complets, verbatim](prompts.json)
- [Morrow Creek — texture PSX](morrow_creek_psx.png)
- [The Long Way Home — texture PSX](the_long_way_home_psx.png)

Les originaux ont un ratio 3:4. Textures techniques : 192 × 256 RGB, réduction Lanczos, sans recadrage du contenu. Filtrage nearest en jeu. Pas de retouche artistique par Pillow. Les quatre panneaux existants partagent ces deux illustrations ; leurs tailles, emplacements, UV et morceaux de ruban restent identiques. Le petit imprimé FIELD NOTES est conservé.

Le statut reste generated ; aucune approbation artistique humaine présumée. Les prompts décrivent une intention artistique, pas de nouvelles décisions de lore. La source d'image est figée dans le projet pour une intégration reproductible hors ligne.
